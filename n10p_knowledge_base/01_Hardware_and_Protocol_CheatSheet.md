# 01 — 硬件与协议速查表 (Hardware & Protocol CheatSheet)

> 对象：镭神智能（Leishen Intelligent）N10P 单线导航避障激光雷达
>
> 最后更新：2026-05-27

---

## 1. 产品概述

N10P 是镭神智能推出的 **360° 二维导航避障激光雷达**，属于 N10 系列（含 N10、N10Plus/N10P）。主要面向室内服务机器人、AGV、清洁消毒机器人等场景，提供定位与障碍物规避能力。

- **官方产品页**：https://www.lslidar.com/product/n10-navigation-obstacle-avoidance-lidar/
- **激光波段**：905nm
- **激光安全等级**：Class I（人眼安全）

---

## 2. 核心技术参数

| 参数项 | 数值 | 备注 |
|--------|------|------|
| 探测距离 | 0.02 ~ 12m @70% 反射率 | 实际有效距离受环境光影响 |
| 测距精度 | ±3cm（0~6m）；±4.5cm（6~12m）@70% | — |
| 视场角（FOV） | **360°** | 无死角覆盖 |
| 水平角度分辨率 | **0.48° ~ 0.96°** | 不同转速下可能有差异 |
| 扫描频率 | 6 ~ 15Hz（典型 10Hz） | 对应 400~1000 rpm |
| 数据点生成 | **4500 pts/s** | @ 10Hz 约 450 点/圈 |
| 重量 | **60g** | 极轻，方便嵌入 |
| 尺寸 | **φ52 × 36.1mm** | 非常紧凑 |
| 防护等级 | IPX-4 | 防溅水 |

> ⚠️ 注意：官网宣传数据为 4500 pts/s。但实际通过数据帧解析推测 N10P 可能为 **720 点/圈 @ 10Hz**（即 7200 pts/s），二者存在出入。**实际点数以串口抓取数据为准**，此处列出的官方数据供参考。

## 3. 硬件接口与供电

### 3.1 物理接口

N10P 采用 **串口（UART TTL）+ USB 转接** 的方式与上位机通信：

| 接口层 | 详情 |
|--------|------|
| 雷达本体接口 | UART TTL 串口 |
| USB 转串口芯片 | **CH9102**（南京沁恒微电子）/ **CP210x**（早期版本） |
| Linux 设备路径 | `/dev/ttyACM0`（CH9102 常见）、`/dev/ttyUSB0`（CP210x）、`/dev/ttyCH343USB0`（视内核驱动而定） |
| 默认波特率 | **460800**（或 230400，需实测确认） |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |
| 流控 | 无 |

### 3.2 供电要求

| 项目 | 参数 |
|------|------|
| 供电电压 | **5V DC**（USB 供电） |
| 供电电流 | 约 200~350mA（正常工作） |
| 功耗 | <2W（估计值） |

> N10P 通常由 USB 接口直接供电，无需外部电源适配器。若使用 USB 集线器，注意总功率是否充足（不稳定的供电可能导致雷达频繁重启）。

### 3.3 指示灯状态含义

| 指示灯状态 | 含义 |
|------------|------|
| 常亮 | 雷达供电正常、系统待机 |
| 慢闪（~1Hz） | 雷达正在旋转扫描 |
| 快闪 | 数据正在传输 |
| 熄灭 | 未供电或故障 |

> ⚠️ 不同批次产品的指示灯行为可能有差异，以上为社区经验归纳，仅供参考。

## 4. 底层通信协议

### 4.1 概览

N10P 通过串口以 **固定帧格式** 单向向上位机发送数据。上位机不需要向雷达发送任何指令，即 **"上电即出数"** 模式。

一个完整的数据包帧结构如下：

```
┌──────┬──────────┬──────────┬──────────────┬──────┐
│ 帧头 │ 转速参数 │ 起始角度 │ N组测距数据  │ 帧尾 │
│ 2B   │ 2B       │ 2B       │ 70×2B        │ 2B   │
└──────┴──────────┴──────────┴──────────────┴──────┘
```

- **帧头**：`0xA5 0x5A`（固定值，标识一帧开始）
- **帧尾**：`0xFA 0xFB`（固定值，标识一帧结束，一些文档可能写为其他变体，以实际抓取为准）

### 4.2 字段详解

| 字段 | 字节数 | 含义 | 解析方式 |
|------|--------|------|----------|
| `header` | 2 | 帧头，固定 `A5 5A` | 用于帧同步 |
| `speed` | 2 | 当前转速参数 | `转速(rpm) = 2,500,000 / speed_value` |
| `start_angle` | 2 | 本帧第一个测距点的绝对角度 | 单位：0.01°（即除以 100 得到度数） |
| `data[0..69]` | 70×2 | 70 组距离数据 | 单位：**毫米 (mm)**，小端序；`0xFFFF` 表示无效点 |
| `tail` | 2 | 帧尾，固定 `FA FB` | 用于帧完整性校验 |

### 4.3 角度计算

每个测距点的角度由下式确定：

```
angle_i = start_angle + (15 / m) × i
```

其中：
- `angle_i` = 第 `i` 个测距点的绝对角度（0.01° 单位）
- `start_angle` = 本帧的起始角度（从帧头读取）
- `i` = 测距点在本帧内的索引（0 ~ 69）
- `m` = 角度细分因子（取决于转速档位）

> 实际公式和参数存在多个版本。社区中有人提出 `angle_CodedDisc + 15/m × N`，但不一定全适用。**建议以驱动源码 `lslidar_driver/` 里 `packet.cpp` 或 `decoder.cpp` 的实现为准。**

### 4.4 无效点判定

距离字段值为 `0xFFFF`（小端序，即两个字节都为 `0xFF`）时，表示该角度方向**无有效回波信号**（超出量程、物体吸收率过高、阳光过强等）。

### 4.5 一帧完整数据量

以一帧包含 70 个距离点为例：
- 帧头 (2) + 转速 (2) + 起始角 (2) + 距离数据 (140) + 帧尾 (2) = **148 字节/帧**

以 10Hz 扫描频率且每圈约 10 帧估算（实际帧数取决于转速），每秒数据量约为 **1480 ~ 2200 字节/秒**。

## 5. CH9102 串口芯片注意事项

CH9102 是南京沁恒微电子生产的 USB 转串口芯片，在 Linux 下的支持情况：

| 内核版本 | 支持情况 |
|----------|----------|
| Linux 5.x | 内核主线支持（`cdc_acm` 驱动），识别为 `/dev/ttyACM0` |
| Linux 6.x | 原生支持，无需额外安装驱动 |
| 旧版 Ubuntu 18.04 | 可能需要手动编译安装 CH9102 驱动 |

**与 CP210x 的区别**：
- CP210x（Silicon Labs）：内核 `cp210x` 驱动，识别为 `/dev/ttyUSB0`
- CH9102（沁恒）：内核 `cdc_acm` 驱动，识别为 `/dev/ttyACM0`

> 如果你的 N10P 识别为 `/dev/ttyUSB0`，说明是较早批次（CP210x 芯片）。如果识别为 `/dev/ttyACM0`，则是较新批次（CH9102 芯片）。
